# Advanced Bank Term Deposit Analysis & Prediction

## Project Overview
This project analyzes bank marketing campaign data to understand customer behavior and predict term deposit subscriptions.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Tasks
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Correlation Analysis
- Feature Engineering
- Logistic Regression Model

## Outcome
Identified key factors influencing customer subscriptions and developed a predictive model for term deposit subscription analysis.
